# Source Code

This folder contains the core Julia implementation for the project:
- `kadabra.jl`: The Julia port of the Kadabra betweenness centrality approximation algorithm.
- `BRAVAGNN.jl`: The Julia implementation of the BRAVA-GNN neural network architecture.
- `train_bravagnn.jl`: Script containing the logic to train the BRAVA-GNN models.
